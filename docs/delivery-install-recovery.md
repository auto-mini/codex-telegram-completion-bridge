# Delivery and installer recovery

The reported task's recent ordinary completions were present as sent events, including a fresh automatic probe. The latest heartbeat was explicitly `DONT_NOTIFY` and correctly had no delivery row. Telegram API acceptance is distinct from seeing a message or push on the recipient's device; recipient confirmation remains separate.

One recorded completion waited approximately 98 seconds after `INSTALL_ACL_BLOCKED`. The old log did not retain the specific ACL error, so its exact underlying failure cannot be proven retrospectively. A related race was reproduced deterministically: an atomic-write temporary file disappears after the ACL checker snapshots directory entries, causing a valid protected installation to be classified unreadable and the worker to exit. The checker now restarts the entire root/tree verification up to three times on file/directory disappearance. Invalid permissions still fail closed, including permissions changed between retries. The worker logs the precise fixed ACL operation code without exposing file paths or content.

The target-PC upgrade had not applied: its result was `desktop_close_timeout` and installed executables remained at the old version. Process-name-only detection also treated the separately installed npm Codex CLI as the desktop application. The installer and waiting helper now exclude only `codex.exe` under the current user's known npm package directory; ChatGPT, the desktop-bundled Codex server, unknown paths, and unreadable processes remain blockers. No user app or unrelated background process is killed.

The hook configurator resolves a native Codex executable instead of attempting to launch an npm `.ps1`/`.cmd` shim with `UseShellExecute=false`. Existing explicit native paths remain supported. Diagnostic collection is scripted and outputs only versions, binary hashes, fixed health/status codes, and process categories; no paths, PC/user names, credentials, or message content are in the transferable report.

Validation: the disappearing-file regression failed before the fix and passed afterward; all 131 unit and 115 integration tests passed. PowerShell syntax and personal rollout safety checks passed.
